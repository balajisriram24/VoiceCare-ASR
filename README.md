# VoiceCare – Voice-Based Smart Assistant for Senior Citizens Using ASR

## Project
VoiceCare is a browser-based ASR project designed around simple voice commands that may be useful for senior citizens. It converts speech to text and detects common daily requests such as medicine reminders, family calls, shopping, daily tasks, travel/hospital assistance and emergency requests.

## Working Flow
**Voice Input → Automatic Speech Recognition → Text → Command Detection → Action/Response**

## Main Modules
- Medicine Reminder
- Family Call Request
- Shopping List
- Daily Task
- Travel / Hospital Help
- Emergency Voice Command
- General Voice Request

## Technologies
HTML5, CSS3, JavaScript and Web Speech API. Google Chrome is recommended.

## Run
1. Extract the project.
2. Open the folder in VS Code.
3. Open `index.html` in Google Chrome, or use Live Server.
4. Click **Start Listening**.
5. Allow microphone access.
6. Speak a command.
7. Click **Stop**, then **Process Command**.
8. The detected command and suggested action appear on screen.

## Example Commands
- "Remind me to take my medicine at 8 PM."
- "Call my son."
- "I need to buy milk and rice."
- "Remember, I have to go to the temple tomorrow."
- "I need a cab to the hospital."
- "Emergency, I need help."

## Important
This prototype demonstrates ASR and command detection. It does not actually place phone calls, send emergency alerts, book cabs, or provide medical advice. Those actions can be connected to real services as future enhancements.
